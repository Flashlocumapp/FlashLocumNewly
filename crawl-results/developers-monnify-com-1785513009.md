# Checkout API

The Checkout API gives you full control over the payment flow without requiring a Monnify SDK. Use it to redirect customers to the Monnify-hosted checkout URL, or build your own payment UI by calling the bank transfer and card charge endpoints directly.

Prefer a library over raw API calls?

Monnify has official server-side libraries for Node.js, Python, Go, Java, PHP (Laravel), and more, so you can skip the boilerplate and integrate in minutes. See [Libraries and Plugins](/docs/integration-tools/plugin-libraries).

## Option A – Hosted Checkout (Redirect to checkoutUrl)

The fastest way to go live. Your server initializes a transaction via the API, receives a checkoutUrl, and redirects the customer to it. Monnify handles the entire payment UI and redirects the customer back to your site when done.

### Step 1 – Authenticate

Base64-encode your apiKey:secretKey and call the login endpoint to get a Bearer token (valid for 1 hour).

## Option B – Build Your Own Payment UI (Raw Endpoints)

If you want to build a fully custom payment flow with your own bank transfer screen and card form, use the raw API endpoints below instead of the hosted checkout URL.

### Pay with Bank Transfer

Call the [Pay with Bank Transfer endpoint](/api#tag/transactions/#pay-with-bank-transfer) with the transactionReference of an initialized transaction. Monnify returns a dynamic virtual account number your customer transfers to.

- You can call this endpoint multiple times; each call returns how many seconds the account remains valid (maximum 2400 seconds / 40 minutes).
- Pass a bankCode to also receive a USSD code for that bank.
- Inform your customers of the account expiry to prevent failed or erroneous transfers.

Note:

The virtual account is valid for 40 minutes. Always display this expiry clearly to your customers.

### Charge Card

Call the [Charge Card endpoint](/api#tag/transactions/#charge-a-card) with the customer's card details and the transactionReference of an initialized transaction.

PCI-DSS required:

Access to the direct card charge endpoint requires PCI-DSS certification. Contact [[email protected]](/cdn-cgi/l/email-protection#177e796372706576637e78793a64626767786563577a7879797e716e3974787a) to apply.

# One-Time Payments

One-time payments are single, non-recurring transactions where a customer pays for a product or service. Monnify gives you several ways to collect these payments, from a fully hosted checkout your customers complete in seconds to a raw API you build your own UI on top of.

Not sure which to use?

Start with the Checkout Page (JS SDK / mobile SDK) for the fastest integration. Use the Checkout API or Invoice if you need a redirect flow, a custom payment UI, or time-bound virtual accounts. Use Payment Links if you want to collect payments without writing any code.

# Integration Options

[## Checkout Page

Embed a Monnify-hosted payment modal in your website or mobile app using the JS, Android, Flutter, or iOS SDK. Customers pay without leaving your platform.

](/docs/collections/one-time-payments/checkout-page)[## Checkout API

Initialize a transaction via the API and redirect customers to the Monnify-hosted checkout URL, or build your own payment UI using the raw bank transfer and card charge endpoints.

](/docs/collections/one-time-payments/checkout-api)[## Payment Links

Generate a shareable payment link from your Monnify dashboard. No code required. Send the link or QR code by email, WhatsApp, or SMS.

](/docs/collections/one-time-payments/payment-links)[## Invoice

Generate invoices via API that give customers a virtual account number and a checkout URL for payment. Supports static and dynamic invoices.

](/docs/collections/one-time-payments/invoice)[## Offline Pay-ins

Accept cash payments from customers through Moniepoint POS Agents. Merchants create offline products and get notified when a customer pays at any agent.

](/docs/collections/one-time-payments/offline-payins)[## WordPress / WooCommerce Plugin

Sell on WordPress? Install the official Monnify WooCommerce plugin to accept card and bank transfer payments directly from your WooCommerce store. No custom code required.

](https://wordpress.org/plugins/monnify-official/)
